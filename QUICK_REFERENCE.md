## 🎯 SCORING FORMULA

### Score Calculation
```
Score = (Correct × Marks) - (Wrong × Negative Marks)

Example:
Questions: 50
Correct: 40
Wrong: 10
Marks/Q: 1
Negative: 0.25

Score = (40 × 1) - (10 × 0.25)
     = 40 - 2.5
     = 37.5/50
```

### Accuracy Calculation
```
Accuracy = (Correct / Total) × 100

Example:
Accuracy = (40 / 50) × 100 = 80%
```

### Ranking
```
Rank = Based on:
     1. Total Marks (Primary)
     2. Accuracy (Secondary)
     3. Quiz Count (Tertiary)
```

## 🚨 TROUBLESHOOTING

### Problem: Quiz not starting
**Solution:** Check internet, restart bot, try Practice mode

### Problem: Low accuracy
**Solution:** Re-read explanations, repeat chapter, focus on weak areas

### Problem: Can't upload file
**Solution:** Check file format (.xlsx/.docx/.txt), file size < 10MB

### Problem: Scheduled quiz not showing
**Solution:** Check start time (must be future date), refresh, wait for time
