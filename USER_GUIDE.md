## 📝 Live Quiz নিন

### Live Quiz কি?
সময়সীমা সহ scheduled exams যা আপনার performance track করে।

### কিভাবে নিবেন?

1. **"📝 Live Quiz"** button ক্লিক করুন
2. Available exams দেখুন:
   - **Exam Name** - কি exam

   - **Explanation** দেখুন
   - **Next** question এ যান

5. **Quiz Complete হলে**:
   - Final Score দেখবেন
   - Results leaderboard এ update হবে

### Live Quiz Tips 💡
- ⏰ সময়ের মধ্যে সব answer করুন
- ✅ প্রতিটি answer carefully check করুন
- 📖 Explanation পড়ুন learning এর জন্য
- 🏆 Leaderboard এ top rank পেতে চেষ্টা করুন

## 📤 Questions Upload করুন

### কিভাবে Upload করবেন?

**Option 1: Dashboard থেকে**
1. **`/admin`** command দিন
2. Admin panel এ **"📤 Upload Questions"** button ক্লিক করুন
3. নিচের steps follow করুন

**Option 2: Direct Command**
1. **`/upload`** command দিন
2. নিচের steps follow করুন

**Both options follow the same upload process:**

### Upload Process:

**Step 1: Exam Name**
```
📝 Exam Name লিখুন।
উদাহরণ: GNM ANM 2027
```

**Step 2: Subject**
```
📚 Subject লিখুন।
উদাহরণ: Anatomy, Physiology, Pathology
```

**Step 3: Chapter**
```
📖 Chapter লিখুন।
উদাহরণ: Chapter 1, Chapter 2
```

**Step 4: Marks**
```
🎯 Marks লিখুন। (যেমন: 1)
প্রতিটি question এর marks
```

**Step 5: Negative Marks**
```
➖ Negative Marks লিখুন। (যেমন: 0 অথবা 0.25)
ভুল উত্তরের জন্য কাটা marks
```

**Step 6: File পাঠান**
```
📤 এখন Question File পাঠান।
Supported Format:
✅ .xlsx (Excel)
✅ .docx (Word)
✅ .txt (Text)
```

### File Format - Excel (.xlsx)

| Column | Content | Example |
|--------|---------|---------|
| A | Question | What is anatomy? |
| B | Option A | Study of structure |
| C | Option B | Study of function |
| D | Option C | Study of disease |
| E | Option D | Study of environment |
| F | Correct Answer | A |
| G | Explanation | Anatomy is the study... |

### File Format - Text (.txt)

```
Question 1. What is anatomy?
A. Study of structure
B. Study of function
C. Study of disease
D. Study of environment
Answer: A
Explanation: Anatomy is the study of structure.

Question 2. What is physiology?
A. Study of function
B. Study of structure
C. Study of disease
D. Study of environment
Answer: A
Explanation: Physiology is the study of function.
```

## Scoring System

### Marks Calculation:
```
Total Score = (Correct Answers × Marks) - (Wrong Answers × Negative Marks)
Accuracy = (Correct Answers / Total Questions) × 100
```

### Example:
```
Total Questions: 50
Correct: 40
Wrong: 10
Marks per Q: 1
Negative: 0.25

Score = (40 × 1) - (10 × 0.25) = 40 - 2.5 = 37.5
Accuracy = (40 / 50) × 100 = 80%
```

## Ranking System

### Calculation:
- ✅ Total marks based
- 📈 Accuracy weighted
- 🎯 Quiz count considered
- 🏆 Weekly reset available

## Admin FAQs

### Q: কয়টা Questions একসাথে Upload করতে পারি?
**A:** File এ যত চাই তত questions রাখতে পারেন। একটি file এ 1000+ questions ও হতে পারে।

### Q: Question Delete করলে Students এর Data কি হবে?
**A:** Student এর quiz responses save থাকবে, কিন্তু Question Data lost হবে।

### Q: Broadcast Message এ কত Characters?
**A:** Telegram এর limit অনুযায়ী (প্রায় 4000 characters)।

### Q: Database Backup কত দিন পর পর করব?
**A:** কমপক্ষে সপ্তাহে একবার নিন। Important data এর পরে immediately নিন।

### Q: Student কে Block করলে তার Data কি হবে?
**A:** Data save থাকবে, কিন্তু সে Bot use করতে পারবে না।

### Q: কিভাবে জানব কয়টা User Active?
**A:** Admin panel → Statistics → Active Users দেখুন।
